# 📊 Jio Customer Churn Analysis Dashboard

## 📝 Project Overview
This project focuses on analyzing customer churn for Jio Telecom. By examining a dataset of 7,043 customers, this interactive Excel dashboard identifies the key drivers behind a 26.54% overall churn rate. The insights generated from this project aim to help telecom stakeholders understand customer behavior, pinpoint high-risk segments, and implement targeted retention strategies.

## 🎯 Key Objectives
*   Calculate and visualize the overall churn rate.
*   Identify high-risk customer segments based on contract type, tenure, and payment methods.
*   Analyze the impact of services (e.g., Jio True 5G vs. JioFiber) on customer retention.
*   Provide actionable, data-driven recommendations to reduce churn.

## 🛠️ Tools Used
*   **Microsoft Excel:** Data cleaning, Power Query, Pivot Tables, and Dashboard visualization.

## 📈 Key Insights Discovered
1.  **Overall Churn:** The current customer churn rate stands at **26.54%** (1,869 out of 7,043 customers).
2.  **The "Pay-As-You-Go" Risk:** Customers on month-to-month/Pay-as-you-go contracts have a severe churn rate of **42.7%**, compared to just 2.8% for users on 2-Year Prime contracts.
3.  **Critical Early Tenure:** The highest drop-off occurs in the first year. Customers with a tenure of **0–12 months** have a churn rate of **47.4%**.
4.  **Service Friction:** Users adopting "Jio True 5G" showed an unexpectedly high churn rate (41.9%) compared to "JioFiber" users (19.0%), indicating potential areas for service or pricing improvement.
5.  **Payment Methods:** Manual payment methods like UPI correlate with higher churn (34.7%) versus automated methods like credit cards (15.2%).

## 💡 Strategic Recommendations
*   **Incentivize Long-Term Contracts:** Push promotions that encourage Pay-as-you-go users to upgrade to 1-Year or 2-Year Jio Prime contracts.
*   **Focus on the First Year:** Implement a dedicated onboarding and loyalty program for users in their first 0-12 months to stabilize the early drop-off rate.
*   **Automate Payments:** Offer discounts or cashback for users who set up automatic bank transfers or credit card payments.
